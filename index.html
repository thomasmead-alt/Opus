▶ Formula Reference
Text
TRIM(value) Remove leading/trailing whitespace
UPPER(value) Convert to uppercase
LOWER(value) Convert to lowercase
PROPER(value) Capitalize first letter of each word
LEFT(value, n) First n characters
RIGHT(value, n) Last n characters
MID(value, start, length) Substring from position (1-based)
LEN(value) Length of text
REPLACE(value, old, new) Replace all occurrences
SUBSTITUTE(value, old, new) Same as REPLACE
CLEAN(value) Remove non-printable characters
REPT(value, n) Repeat text n times
Extract & Split
SPLIT(value, delim, index) Split by delimiter, return part at index (0-based)
EXTRACT(value, pattern) Extract first regex match
TEXTBEFORE(value, delim) Text before first delimiter
TEXTAFTER(value, delim) Text after first delimiter
Combine
CONCATENATE(a, b, ...) Join values together
CONCAT(a, b, ...) Same as CONCATENATE
TEXTJOIN(delim, a, b, ...) Join values with delimiter
Numbers
VALUE(text) Convert text to number
TEXT(number, format) Format number (e.g. "0.00")
ROUND(number, decimals) Round to decimal places
ABS(number) Absolute value
INT(number) Truncate to integer
Date
DATEFORMAT(value, format) Reformat date (YYYYMMDD, DD.MM.YYYY, etc.)
YEAR(value) Extract year
MONTH(value) Extract month
DAY(value) Extract day
Logic
IF(cond, then, else) Conditional: IF(value=="", "N/A", value)
IFERROR(expr, fallback) Return fallback if expr errors
ISBLANK(value) TRUE if empty
DEFAULT(value, fallback) Use fallback if value is blank
Lookup
LOOKUP(dataset, field) Lookup field from external dataset by composite key
Special
LPAD(value, length, char) Left-pad to length with char
RPAD(value, length, char) Right-pad to length with char
CHANGE(old, new, old2, new2, ...) Map values: if old return new, ...
